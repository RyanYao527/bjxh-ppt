# 北京兴华 PPT 素材库

源文件：`3、北京兴华PPT模版.pptx`

## 素材概览

- 总页数：121
- 提取图片：17 张
- 提取表格：10 个

## 目录说明

- `renders/`：每页 PPT 的 PNG 预览（150 DPI），用于快速浏览素材。
- `images/`：从 PPT 中直接提取的原始图片文件。
- `tables/`：表格数据，每个表格一个 CSV 和一个 JSON。
- `text-snippets.md`：每页的文字内容汇总，便于复制使用。
- `index.json`：机器可读的素材索引。

> **注意**: `renders/` 目录目前仅包含 51/121 页的 PNG 预览，不完整。
> 如需完整的预览图，请运行：
> ```bash
> python scripts/extract_assets.py "3、北京兴华PPT模版.pptx" assets/
> ```
> 需要 LibreOffice + PyMuPDF (fitz)。

## 使用方式

1. 在 `renders/` 中浏览找到需要的素材页。
2. 若需要原始图片，到 `images/` 查找对应 slide 的文件。
3. 若需要表格数据，到 `tables/` 查找 CSV/JSON。
4. 若需要文字内容，直接参考 `text-snippets.md`。
