# bjxh-ppt

**北京兴华会计师事务所 PPT 制作规范** — A skill that turns a Markdown outline into a brand-compliant `.pptx` based on the Beijing Xinghua (BJXH) 2026 partner-meeting master template.

- **画布尺寸**: 13.333" × 7.5" (16:9 widescreen)
- **版式库**: 80 layouts inherited from the master template
- **输入格式**: Markdown outline (H1 cover / H2 chapters / H3 pages / bullets / directives)
- **输出格式**: `.pptx` (PowerPoint native, no rendering step needed)
- **执行档位**: Medium constraint — locks canvas / fonts / sizes / common layouts; allows flexibility on charts and animation

## Why this skill exists

Internal BJXH staff produce dozens of partner-meeting / audit-review / business-report decks a year. Hand-crafting each one against the brand template is slow and inconsistent. This skill encodes the brand rules (color palette, type scale, layout selection, common patterns) into a script that:

1. Validates the outline structure
2. Selects the right master layout per section
3. Fills placeholders with the right font / size / color
4. Runs a 9-rule QA check before output
5. Stays editable in PowerPoint — the output is a real `.pptx`, not an image or PDF

## Quick start

```bash
# 1. Install Python deps
pip install python-pptx

# 2. Write your outline in examples/audit_demo.md style
# (H1 = cover, H2 = chapter, H3 = page, "- ..." = bullet, "> layout: X" = override)

# 3. Generate
python scripts/from_outline.py my_outline.md my_output.pptx

# 4. Self-audit (9-rule check)
python scripts/qa.py my_output.pptx

# 5. Open in PowerPoint, fine-tune, re-run qa.py
```

The first run without arguments uses the default template at
`C:\工作\04-总结与报告\2026年工作\2026合伙人大会\北京兴华模板.pptx`.
Pass a third argument to override:
```bash
python scripts/from_outline.py my_outline.md my_output.pptx /path/to/your/template.pptx
```

## What the skill enforces

| Rule | Source | Detail |
|---|---|---|
| Canvas | 13.333" × 7.5" | [SKILL.md §2](SKILL.md) |
| Forbidden fonts | 宋体 / SimSun / Calibri / Georgia … | [SKILL.md §2](SKILL.md) |
| Font sizes | Cover 66pt, body 14pt, footer 10pt | [SKILL.md §3](SKILL.md) |
| Color palette | 30% brand red (200,20,40), 50% light gray, 10% dark accents | [SKILL.md §3](SKILL.md) |
| Line spacing | 1.3 | [SKILL.md §3](SKILL.md) |
| Layout variety | ≥ 3 distinct layouts | [SKILL.md §6.4](SKILL.md) |
| Essential placeholders filled | No empty `THANKS` / `北京兴华集团` | [SKILL.md §6.2, §6.3](SKILL.md) |
| No template residue | No isolated `B` / `J` / `H` / `X` letters | [SKILL.md §7](SKILL.md) |
| Visual element per slide | Content slides ≥ 4 shapes | [SKILL.md §6.4](SKILL.md) |

## Requirements

- **Python**: 3.11+ (tested on 3.11)
- **Dependencies**: `python-pptx`, `lxml`
- **OS**: Windows / macOS / Linux (template path defaults to Windows path; override via CLI arg)
- **Optional**: Microsoft PowerPoint (for final visual review and fine-tuning)

## Re-generating template_spec.json

```bash
python scripts/dump_template_spec.py /path/to/master_template.pptx > template_spec.json
```

This reads every layout's placeholders, text frames, and decoration shapes
from the master template, and writes a machine-readable spec. Run this once
when the master template changes.

## Adapting to your own template

This skill is parameterized entirely through the master template path. To use
it with a different brand template:

1. Drop your `.pptx` somewhere accessible.
2. Copy `scripts/config.example.json` to `scripts/config.json` and set `template_path`.
   Alternatively, set the `BJXH_TEMPLATE` environment variable, or pass the path as
   the third CLI argument to `from_outline.py`.
3. Re-run `dump_template_spec.py` against the new template to refresh
   `template_spec.json`.
4. Adjust the layout names in `scripts/render.py → PLACEHOLDER_MAP`
   to match the new template's layout names.
5. Update the size / color rules in `SKILL.md §2-§3` if your brand differs.
